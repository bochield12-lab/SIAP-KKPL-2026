# SIAP-KKPL-2026

SIAP 2026 adalah aplikasi berbasis web (*Progressive Web App*) yang dirancang khusus untuk mempermudah pencatatan presensi harian, pelaporan jurnal kegiatan (KKN & PPL), serta pemantauan kalender program kerja bagi seluruh anggota kelompok KKPL Sukowiyono 2026.

---
 Fitur Utama

- **Presensi GPS & Real-time Camera**  
  Mencatat kehadiran anggota secara aktual menggunakan koordinat GPS (*geolocation*) dan verifikasi foto wajah langsung (*live selfie*).
-  **Jurnal Kegiatan Dual-Mode**  
  Pencatatan laporan harian terintegrasi untuk kegiatan **KKN** (Kuliah Kerja Nyata) maupun **PPL** (Praktik Pengalaman Lapangan).
-  **Kalenderisasi & Monitoring Proker**  
  Pantau progres, target, dan Penanggung Jawab (PJ) dari setiap program kerja kelompok secara *real-time*.
-  **Integrasi Google Sheets Backend**  
  Seluruh data terhubung langsung ke Google Sheets secara otomatis via Google Apps Script sebagai *database* terpusat.
